# 我的知识库

一个零依赖的静态知识库：笔记用 Markdown 写，一条命令生成网站，`dist/` 丢到哪里都能跑。
适合「学了东西先记下来，以后回头翻」的用法。

**线上地址：https://ycc52054.github.io/my-blog/** —— 推送到 GitHub 后会自动更新，上线过程见 [DEPLOY.md](DEPLOY.md)。

## 四个「按钮」

不用敲任何命令，双击下面这几个文件就行：

| 双击这个 | 它做什么 |
| --- | --- |
| **写新笔记.cmd** | 一步步问你文件名、标题、主题标签，建好文件后用 VS Code 打开；写完关掉编辑器，它会问你要不要顺手发布 |
| **本地预览.cmd** | 生成网页并自动打开 http://localhost:4321 看效果（那个黑色窗口别关，关了预览就停了） |
| **发布上线.cmd** | 生成网页 → 提交 → 推送到 GitHub，一两分钟后线上自动更新 |
| **关闭预览.cmd** | 关掉本地预览 |

（同目录下的 `write.cmd` / `start.cmd` / `publish.cmd` / `stop.cmd` 是它们对应的命令行版本，用来写脚本的，平时双击中文名的那个就好。）

## 快速开始

想用命令行的话：

```bash
node new.js flex-layout "Flex 布局速查" 前端,CSS   # 新建一篇笔记
node build.js                                      # 生成网站到 dist/
node serve.js                                      # 本地预览 http://localhost:4321
```

`npm run dev` 等于「构建 + 预览」。

## 日常写笔记的完整流程

```powershell
node new.js flex-layout "Flex 布局速查" 前端,CSS   # 1. 新建笔记（也可以直接复制现有的 .md 改）
# 2. 用编辑器写内容，存盘
node build.js                                      # 3. 本地生成、检查有没有写错
node serve.js                                      # 4. 本地预览 http://localhost:4321
git add . ; git commit -m "新增：Flex 布局速查" ; git push   # 5. 发布上线
```

第 5 步也可以直接双击 `publish.cmd` 代替。

> 网页打不开时先看两件事：**黑色的预览窗口是不是被关掉了**，以及地址是不是 `http://localhost:4321`。
> 直接双击 `dist/index.html` 也能看页面，但那样搜索功能会失效，因为浏览器不允许本地文件读取 `search.json`。

### 打不开 / 连接不上怎么办

预览不是「装好就一直开着」的东西，它只在 `start.cmd` 那个黑色窗口开着的期间有效：

1. 黑窗口关掉了 → 双击 `start.cmd` 重新开一个，浏览器会自动打开。
2. 浏览器还停在旧页面 → 按 F5 刷新；地址要写 `http://localhost:4321`（别少了 `http://`）。
3. 提示「端口已被占用」→ 通常说明预览本来就在运行，直接打开浏览器访问那个地址即可；用 `stop.cmd` 可以把它关掉重来。
4. 换端口：`$env:PORT = 4400; node serve.js`，然后访问 http://localhost:4400。

## 写笔记的格式

文件放在 `content/posts/`，文件名就是网址。用 `node new.js` 会自动带好模板：

```markdown
---
title: 笔记标题
date: 2026-10-09
updated: 2026-10-12   # 可选，改过之后填上，页面会显示「更新于」
tags: 前端, CSS        # 逗号分隔，中文逗号也行
draft: true           # 可选，写 true 就暂时不生成这一页
---

## 一句话总结

用一句自己的话写清楚它是什么、解决什么问题。

## 核心内容

- 支持无序列表、有序列表、引用、代码块、**加粗**、`行内代码`、[链接](https://example.com)

## 相关
```

## 从别处复制 Markdown 粘贴进来

可以。把别处的内容复制、粘到 `content/posts` 里的 `.md` 文件就行，差别在于你是从哪儿复制的：

- **从别的 `.md` 文件 / Obsidian / VS Code 复制** → 直接能用，格式都在。
- **从网页、Word、微信里复制** → 带过来的是「富文本」，直接粘会变成一大段，或者夹着 HTML 标签。先在 VS Code 里按 `Ctrl+Shift+V`（粘贴为纯文本），或者先粘进记事本再复制一次。
- **从 Notion / 语雀 / 飞书导出** → 选「导出为 Markdown」再复制，最干净。

要让粘进来的内容变成一篇正常的文章，需要两样东西：

1. 文件放在 `content/posts/` 里，以 `.md` 结尾（**文件名就是网址**，别用空格）；
2. 文件开头有那段 `---` 信息块。没有也能显示，只是标题会用文件名、没有日期和主题标签。

最省事的做法：双击 **写新笔记.cmd** 建好文件（信息块自动就位），再把你复制的内容粘进去替换模板文字。

实测支持这些写法：

- 标题 `# 一级` ~ `### 三级`（二三级会自动进「本篇目录」）
- 加粗 `**文字**`、斜体 `*文字*`、删除线 `~~文字~~`
- 行内代码 `` `code` `` 和三引号包起来的代码块
- 列表 `- 项` / `1. 项`，任务清单 `- [ ] 待办` / `- [x] 完成`（显示成 ☐ / ☑）
- 引用 `> 文字`、分隔线 `---`
- 链接 `[文字](https://example.com)`
- 图片 `![说明](assets/images/a.png)` —— 把图片放进 `assets/images/` 文件夹，写这个相对路径就行
- 表格：竖线分隔，第二行用 `---|---` 划出表头，`:` 可以控制对齐
- 双链 `[[另一篇笔记的标题]]`

会**原样显示、不会渲染**的写法（粘贴时注意）：嵌套列表（第二层会被拍平）、脚注、数学公式（LaTeX）、HTML 标签，以及表格单元格里再出现 `|` 字符。

## 想要更像「写作软件」的界面？装 Obsidian

「写新笔记.cmd」够用，但如果你想要一个真正的笔记界面（左侧列着所有笔记、边写边看效果、能看到谁引用了谁），可以装 [Obsidian](https://obsidian.md)（免费）：

1. 装好后选 **Open folder as vault**，指向这个 `blog` 文件夹。
2. 左侧文件列表里找到 `content/posts`，双击就能写；在这里新建的文件也是一个 `content/posts` 里的 `.md`。
3. Obsidian 的 `[[双链]]` 语法和这个博客完全一致，敲 `[[` 会提示已有笔记的标题；它侧边栏的「反向链接」就是我们页面上「哪些笔记提到了它」的来源。
4. 写完存盘，双击 **发布上线.cmd** 就发布（Obsidian 不会自动发布，这也是它不会偷偷改你东西的原因）。

唯一要注意的：在 Obsidian 里给文件改名等于改网址，改完记得跑一次发布；旧的链接（如果外面有人收藏过）会失效。

## 让回顾真的发生

- 每篇开头都写「一句话总结」，回顾时只看这一句就够，不必重读全文
- 笔记里随手 `[[链接]]` 到相关笔记，攒起来就是一张网，比按时间翻有效
- 学完一段时间后打开「主题」页扫一遍，看到陌生的标题就点进去补一句
- 内容有变化就填 `updated`，页面会显示更新时间，方便知道哪些是新的

## 改站点信息

打开 `build.js`，最上面的 `SITE` 里改标题、描述、作者；上线后把 `url` 改成你的域名，RSS 才会是绝对链接。

## 换成自己的样式

全部样式在 `assets/style.css`，跟随系统自动切换浅色/深色。改配色只需要动文件开头那几个 CSS 变量。

## 发布上线

`dist/` 是纯静态文件，选一家免费托管就行：

- **Cloudflare Pages / Vercel / Netlify**：连上 Git 仓库，构建命令 `node build.js`，输出目录 `dist`，之后推代码自动更新。
- **GitHub Pages**：用 Actions 跑 `node build.js`，把 `dist/` 发布出去。
- **自己的服务器**：把 `dist/` 传上去，Nginx 指向这个目录。

想用自己的域名，在域名服务商买一个，在托管平台绑定并按提示加 DNS 记录，HTTPS 一般是自动的。

```

本地预览.cmd            双击：生成并在浏览器里预览
发布上线.cmd            双击：提交并推送到 GitHub
关闭预览.cmd            双击：关掉本地预览

build.js              生成器（站点信息、模板都在这里）
write.js / new.js     新建笔记的内部实现（问答式 / 命令行）
note.js               笔记模板，两个入口共用
publish.js            一键发布的实现
dev.js / serve.js     构建 + 本地预览
stop.js               关闭预览的实现
assets/style.css      样式
assets/search.js      搜索页的脚本
content/posts/*.md    笔记（你的内容都在这里）
dist/                 生成结果，不用手改，也不建议提交到 Git
```
